# 🏐 Beach Volleyball ETL & Analytics System

An advanced Data Engineering project that processes over 60,000 professional volleyball match records.

## 🚀 Features
- **ETL Pipeline:** Extracting data from CSV, cleaning, and loading into SQLite.
- **Smart Imputation:** Filling missing values using teammate-based logic.
- **Interactive Dashboard:** Built with Streamlit for real-time EDA.
- **SQL Integration:** Manual match entry and persistent storage using SQLAlchemy.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Streamlit, SQLAlchemy, Seaborn.
- **Database:** SQLite

## 📊 Sample Insights
- Winners tend to have a slightly higher average height than losers.
- Gender distribution is highly balanced in international circuits.
